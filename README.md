# Our team page

A shared HTML, CSS, and JavaScript page for the team activity. Erin's card includes her program, the supplied Teachers College image, and an expandable fun fact.

## View the page

Open `index.html` in a browser. No installation or build step is needed.

## Add your card

1. Pull the latest changes from `main` before starting your turn.
2. Copy the `article.team-card` in `index.html` and add it inside `section.team`.
3. Give your heading a unique ID and update the article's `aria-labelledby` to match.
4. Replace the name, program, school, image, alternative text, and fun fact with your information. Save your image in `assets/`.
5. Check the layout and fun-fact toggle in a browser, including a narrow window.
6. Commit and push your changes, then let the next teammate know it is their turn.

Keep the shared styles in `styles.css` and interactions in `script.js`.

The repository owner can publish through GitHub Pages by choosing `main` and `/ (root)` in the repository's Pages settings.
